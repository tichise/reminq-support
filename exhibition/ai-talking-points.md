# Reminq × 生成AIなんでも展示会 — 説明用トーキングポイント

展示会場で Reminq を説明するときの台本兼チートシート。展示プレート (`exhibition/reminq-ai-exhibition-plate.pptx`) と整合させ、口頭デモ用に AI 周りを厚めにしている。

---

## Reminq とは（30 秒で）

- iOS 26+ / iPadOS 26+ / macOS 26+ 向け、**Apple 標準リマインダーを LLM が読み解く**カンバン型タスクアプリ
- **データの真実は常に Apple リマインダー側**（EventKit 経由で双方向同期）。Reminq をアンインストールしてもタスクは Apple リマインダーに残る
- 完全無料・サブスクなし。LLM を使う部分だけ **BYO API キー**で、ユーザー自身の OpenAI 残高から従量課金

## LLM をどう使っているか（コア）

- **AI タスク分解**: 「資料を作る」のような曖昧で大きな 1 行を、実行可能な小ステップ群へ展開
  - 入力: タスク文字列（リマインダーのタイトル）
  - 経路: 端末 → **OpenAI Chat Completions API** → 構造化レスポンス
  - 出力: 実行ステップの配列（チェックボックス UI で 1 件ずつ採用 / 棄却できる）
- **優先度ラベリング (High / Mid / Low) を同時生成**
  - 分解と優先度を**別呼び出しにせず 1 回のレスポンスで同時に返させる**設計
  - レイテンシとトークンコストを抑えつつ、「順番に並べた根拠」もモデル側に持たせる
- **Human-in-the-loop が前提**
  - LLM の出力をリマインダーに直接書き込まない。**ユーザーがチェックを入れたものだけ** Apple リマインダーへ静かに反映
  - 「AI = 提案担当 / 人間 = 最終決定」のラインを UI で明示
- **付箋カメラ取り込み**: 手書きメモ・紙の付箋を撮影 → デジタルタスクに変換（マルチモーダル系の入口）

## アーキテクチャと設計判断（LLM 好きに響くポイント）

- **中継サーバーなし**: AI への通信は端末から OpenAI へ直接。Reminq 側のバックエンドは存在しないので、プロンプトもタスク内容もアプリ運営者を通らない
- **BYO API キー**: ユーザーが自分のキーを設定する方式。**運営の集約レート制限 / モデル選定の縛り**から自由で、ユーザー側で利用量と費用が完全に把握できる
- **構造化レスポンス前提のプロンプト**: ステップ配列 + 優先度フィールドを 1 ショットで返させる。アプリ側はそれをそのまま UI コンポーネントへバインド
- **失敗に強い前提**: 出力がそのまま反映されない（人間がチェック）ので、ハルシネーションや粒度の外れは UX を破壊しない。**LLM 出力を破棄可能な「下書き」として扱う**設計
- **オプトイン**: AI 機能を使わない限り、リマインダー本文は外部送信されない。プライバシーポリシー上「AI 機能利用時を除く」が明示

## なぜこの形なのか（プロダクト側の主張）

- フラットなリマインダーは「粒度も優先度も自分で考えて」と利用者に押し付ける。**書いた瞬間に止まるタスク**の正体はそこ
- LLM の「とりあえず最初の一歩を出す」能力が、リマインダーの**最大の弱点**を埋める
- ただし「AI に全権委任」ではない。Apple リマインダーという**ユーザー所有のデータストア**を尊重し、AI は提案までで止める
- 結果として、データ所有権・プライバシー・コスト・モデル選択の自由度すべてをユーザーに残したまま、LLM の実用価値だけを取り込める

## ついでに語れる周辺機能

- **カンバン (TODO / 進行中 / 完了)** — AI が分解したステップを優先度付きで並べ、ドラッグで状態遷移
- **アクティビティ解析** — 週次・月次グラフ。AI 分解と組み合わせると「止まりやすいタスク・続けられているテーマ」がデータで見える
- **GitHub Issue 変換 (ベータ)** — リマインダーをワンタップで Issue 化（開発者向けユースケース）
- **ホーム画面ウィジェット** — タスク状況を一目で
- **多言語**: 日本語 / English

## 想定される来場者からの質問と返し（チートシート）

- 「モデルは？」 → OpenAI Chat Completions 互換。BYO キー方式なのでユーザーが選んだモデルで動く
- 「プロンプトは？」 → タスク文字列 → ステップ配列 + 優先度を 1 ショットで返させる構造化生成。中継サーバーがないので往復は端末 ↔ OpenAI のみ
- 「ハルシネーションは？」 → 反映前にチェックボックス採用が必須。間違っていても「下書き」として無害化
- 「サーバー側に送られる？」 → Reminq の中継サーバーは存在しない。AI 通信はユーザー → OpenAI 直通、それ以外はすべて端末内 + Apple リマインダー
- 「課金は？」 → アプリは完全無料。AI を使うときのみユーザー自身の OpenAI 残高から従量課金
- 「対応 OS は？」 → iOS / iPadOS / macOS 26+
