# Reminq サポートページ

このリポジトリは、iOS・iPadOS・macOS の標準リマインダーをカンバンボードで管理するタスク管理アプリ「Reminq」のサポート用です。サポートサイト（[tichise.github.io/reminq-support](https://tichise.github.io/reminq-support/)）のソースもここで管理しています。

## アプリの特徴

- カンバンボード表示: リマインダーのリストをそのままボードとして表示し、進捗を一目で確認
- 標準リマインダーと完全同期: iPhone・iPad・Mac の標準リマインダーアプリと EventKit 経由で自動同期
- ドラッグ＆ドロップ: タスクの状態を「TODO」「進行中」「完了」の3段階でかんたんに切り替え
- AI タスク分解（オプション）: 大きなタスクを AI が適切なサイズに分解（OpenAI API キーを設定して利用）
- 付箋カメラ取り込み: 手書きメモや紙の付箋を撮影してデジタルタスクに変換
- アクティビティ解析: 週・月単位のグラフ表示で活動量を可視化
- ウィジェット対応: ホーム画面のウィジェットからタスクの進捗をすばやく確認
- GitHub Issue 変換（ベータ）: 登録したリマインダーをワンタップで GitHub Issue に変換

## 対応環境

- iOS 26+
- iPadOS 26+
- macOS 26+
- 言語: 日本語 / English

## プライバシー

データはすべて端末内のリマインダーに保存され、外部サーバーへの送信はありません（AI 機能利用時を除く）。詳細は [プライバシーポリシー](https://tichise.github.io/reminq-support/privacy-policy.html) をご覧ください。
